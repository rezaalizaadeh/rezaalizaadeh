Screening-oriented physiological-signal prototype exploring accessible cardiovascular risk follow-up through an ear-worn device and companion software.

- Develop PPG/ECG signal-processing and ML workflows
- Explore HRV, pulse transit time, waveform morphology, and blood-pressure-derived labels
- Coordinate ML, software, hardware, and product workstreams

### 🍽️ [Padova Restaurant RAG](https://github.com/rezaalizaadeh/padova-restaurant-rag)

Source-grounded question-answering system over restaurant reviews, designed to retrieve relevant evidence before generating an answer.

- SentenceTransformers embeddings and FAISS retrieval
- Aspect-aware hybrid ranking
- Evidence-backed response generation
- FastAPI and command-line interfaces
- Docker packaging, automated testing, and CI

**Stack:** Python · SentenceTransformers · FAISS · FastAPI · Docker · pytest · GitHub Actions

---

### ⚡ [Italy Renewable-Share Forecasting](https://github.com/rezaalizaadeh/renewable-share-forecasting-italy)

Reproducible time-series study comparing statistical and machine-learning approaches for forecasting Italy’s daily renewable electricity share.

- 1,826 daily observations covering 2021–2025
- Complete 2025 time-aware holdout
- Seasonal baselines, ETS, and ARIMA
- Regularized regression, GAM, and Random Forest
- Full-year and rolling one-step-ahead evaluation

**Stack:** R · Time Series · ARIMA · ETS · GAM · Random Forest · Temporal Validation

---

### 🐋 Cetacean Acoustic Classification

Embedded machine-learning thesis connecting acoustic feature engineering, convolutional modelling, and resource-constrained deployment.

- MFCC-based acoustic preprocessing
- Compact 2D convolutional neural network
- **83% held-out test accuracy**
- TensorFlow Lite conversion feasibility
- Arduino Nano 33 BLE deployment target

**Stack:** Python · MFCC · TensorFlow/Keras · 2D CNN · TensorFlow Lite · Edge AI

---

### 🧠 [Visual Concept Learning](https://github.com/rezaalizaadeh/visual-concept-learning)

Study of how internal representations evolve across convolutional neural-network layers using EMNIST Letters and Fashion-MNIST.

- Linear read-outs and representation geometry
- Clustering and confusion-matrix analysis
- Psychometric curves
- Adversarial robustness experiments

**Stack:** Python · PyTorch · torchvision · scikit-learn · NumPy · pandas · Matplotlib
